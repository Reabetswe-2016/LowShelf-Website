# LowShelf Website

## Project Overview

LowShelf is a website developed for Lowveld Shelving and Racking.
The website provides information about the company's products,
services and contact options.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub

## Website Pages

- Home
- About Us
- Products
- Gallery
- Request a Quote
- Contact Us
- Sitemap

## Responsive Design

The website has been designed to work across desktop, tablet
and mobile screen sizes.

CSS media queries, relative units, Flexbox and CSS Grid are used
to create a responsive layout.

## In-Text Reference
Company information
Lowveld Shelving and Racking is a South African company based in White River, Mpumalanga, specialising in industrial shelving, warehouse storage solutions and shopfitting (Lowveld Shelving and Racking, n.d.). The location and business information were also verified using Apple Maps (Apple Inc., 2026).

Responsive design
The website was designed using responsive principles to allow the layout to adapt to different screen sizes, including desktop, tablet and mobile devices (W3C, n.d.).

CSS Grid
CSS Grid was used to organise the product content into multiple columns on larger screens and fewer columns on smaller screens. This approach allows content to reflow according to the available viewport (W3C, 2026b).

Media queries
Media queries were implemented to apply different CSS rules at different screen widths, allowing the website layout to change according to the user’s device (W3C, 2026a).

Accessibility
Accessibility considerations were included by providing alternative text for meaningful images and ensuring that content remains usable across different devices (W3C, 2024).
